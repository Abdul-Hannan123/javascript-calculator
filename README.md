# 🧮 JavaScript Calculator

A modern and responsive Calculator App built using HTML, CSS, and JavaScript. This project allows users to perform basic arithmetic calculations through a clean interface with a neumorphic design.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Number input using calculator buttons
- 🟰 Calculate results using the equals button
- 🧹 AC button to clear the entire input
- ⌫ DE button to delete the last entered character
- 🔹 Decimal point support
- 🎨 Modern neumorphic user interface
- 📱 Responsive design for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Use

1. Open the calculator in your browser.
2. Click the number buttons to enter a calculation.
3. Select an arithmetic operator: `+`, `-`, `*`, or `/`.
4. Click the `=` button to display the result.
5. Click `AC` to clear the complete input.
6. Click `DE` to delete the last entered character.
7. Use the decimal point to perform decimal calculations.
